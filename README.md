# ☁️ AWS Cloud Infrastructure Project

A practical cloud computing project focused on designing, deploying and managing a secure cloud infrastructure using Amazon Web Services (AWS).

## 📌 Project Overview

This project demonstrates the practical implementation of cloud infrastructure using AWS services.

The infrastructure is designed to separate public-facing web resources from private database resources while applying cloud networking, security, scalability and availability principles.

## 🎯 Objectives

- Design a cloud-based network infrastructure
- Create and configure an AWS VPC
- Implement public and private subnets
- Deploy an EC2 web server
- Configure Internet Gateway and route tables
- Configure security groups
- Implement secure network communication
- Separate public web services from private database resources
- Test network connectivity and infrastructure functionality
- Apply AWS cloud security best practices

## 🏗️ AWS Architecture

The planned architecture includes:

- Amazon VPC
- Public Subnet
- Private Subnet
- Internet Gateway
- Route Tables
- Amazon EC2
- Security Groups
- Web Server
- Database Layer
